# Michiru
An easy to use self-hosted Discord bot made for encouraging activity.

## Features
Bot has two main features to keep your members active:
- QOTD (Question of the day):
 - Fully customisable question cards, supporting images
 - Customisable QOTD deck cooldowns
 - QOTD suggestions for members
- Talking streak:
 - Role rewards
 - Displaying the streak in user's name
 - Notifying users when they lose their streak
- General:
 - Huge variety of customisation

## Getting started
To start up a bot:
1. Create an application at the [Discord Developer Portal](https://discord.com/developers/applications).
2. Enable all intents under the Bot tab.
3. Get the token for your bot. **Keep this at a safe place!**
4. Open "PUTYOURTOKENANDIDHERE.py" using a code editor (Notepad will work too!), and paste your application ID and token at the right places.
5. Run "main.py" script to start the bot. If you host it on your device, you'll need to download [**pycord**](https://guide.pycord.dev/installation) library using pip!
